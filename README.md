# الملك ماثيو 👑

تطبيق تعليمي تفاعلي لطفل في KG1، يجمع بين التعلم بالعربية وMath والإنجليزية والبرمجة، مع شرح مبسط قبل الاختبار ومكافآت للإنجاز.

## الموجود حالياً
- **الحساب بالعربي:** الأرقام العربية الهندية، العدّ، المقارنة، الجمع والطرح والأشكال.
- **Math in English:** أسئلة حساب باللغة الإنجليزية وبالأرقام الإنجليزية، في قسم مستقل.
- **مدرسة الحروف العربية:** الحروف الـ٢٨ كاملة، وأشكال الحرف في أول ووسط وآخر الكلمة، وأمثلة كلمات، والفتحة والضمة والكسرة والسكون، ثم اختبار.
- **English A–Z:** الحروف الـ٢٦ مع كلمات وصور ونطق.
- **رحلة الأرقام ١–٢٠:** عرض الرقم واسمه بالعربي مع صور وعدّ مسموع.
- **مغامرة البرمجة:** خمسة مستويات لتعليم ترتيب الأوامر، الحركة، تصحيح الأخطاء، والتكرار باستخدام روبوت ومهام متدرجة.
- **الألوان والأشكال والمعلومات العامة** واختبار مختلط.
- اختيارات مرئية بالصور والكلمات، وشرح للإجابة عند الخطأ، وخلط عشوائي للأسئلة والإجابات.
- **لوحة ولي الأمر:** محاولات ماثيو ودقة كل مهارة والجولات والوقت ومؤشر إتقان إرشادي.
- **الصوت:** جسر Android Text-to-Speech، مع تحويل بعض صياغات الأسئلة إلى العامية المصرية، واختيار الصوت العربي أو الإنجليزي حسب الجهاز.
- حفظ النجوم والتقدم محلياً، وملفات PWA وService Worker للعمل دون إنترنت بعد التحميل الأول.

## التشغيل
انشر الموقع على HTTPS وافتحه مرة بالإنترنت حتى تُخزَّن الملفات. بعد ذلك يعمل المحتوى المحلي دون اتصال. جودة الصوت وتوفر صوت أنثوي محلي والعمل دون إنترنت تعتمد على محرك الأصوات المثبت في الهاتف؛ ويجب اختبارها على جهاز ماثيو الفعلي. التعرف على الكلام قد يحتاج إنترنت حسب المتصفح.

## إنشاء APK
يوجد GitHub Actions workflow في `.github/workflows/android-apk.yml` يشغّل اختبارات المحتوى، ويجهز ملفات الويب، ثم يبني APK تجريبياً عبر Capacitor. بعد نجاح البناء يظهر artifact باسم `king-matthew-debug-apk` في صفحة تشغيل Actions.

هذا APK من نوع debug للاختبار والتثبيت، وليس إصداراً موقعاً للنشر على Google Play.

## حدود يجب التحقق منها
- اختبارات المحتوى وفحص صياغة JavaScript لا تغني عن تجربة التطبيق على هاتف أندرويد فعلي.
- يجب التأكد من اتجاه النصوص والصوت العربي/الإنجليزي والعمل دون اتصال بعد تثبيت APK.
- تقرير ولي الأمر مؤشر متابعة مبدئي وليس تشخيصاً تعليمياً.
