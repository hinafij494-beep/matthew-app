# الملك ماثيو 👑

تطبيق تعليمي للأطفال باللغة العربية، باتجاه RTL، ومصمم للعمل دون اتصال بعد أول فتح ناجح.

## الأقسام الحالية
- عالم الأرقام والاختبارات.
- الحروف والكلمات، الألوان والأشكال، ومعلومات ممتعة.
- مدرسة الحروف الحالية: شرح وتمهيد ثم اختبار.
- أكاديمية الملك ماثيو: الحروف العربية الـ٢٨، الحروف الإنجليزية A–Z، الأرقام من ١ إلى ٢٠، وتحديات برمجة مبسطة لتعليم ترتيب الأوامر والخوارزميات.
- تدريب الاستماع والنطق حسب إمكانات الصوت في جهاز Android والمتصفح.
- نجوم وأفضل نتيجة محفوظة محلياً.
- Service Worker يخزن ملفات الأكاديمية الجديدة للعمل دون إنترنت بعد أول تحميل.

## التشغيل
انشر الموقع على HTTPS وافتحه مرة بالإنترنت حتى تُخزَّن الملفات. الصوت يعتمد على الأصوات المثبتة في الجهاز؛ وقد يحتاج التعرف على الكلام إلى الإنترنت حسب المتصفح.

## إنشاء APK
يوجد Workflow في `.github/workflows/android-apk.yml` لبناء APK تجريبي عبر Capacitor عند الدفع إلى main أو تشغيله يدوياً من GitHub Actions. بعد نجاحه، يظهر artifact باسم `king-matthew-debug-apk` ويمكن تنزيله من صفحة تشغيل workflow.

هذا APK من نوع debug للاختبار والتثبيت، وليس إصداراً موقعاً للنشر على Google Play.

## ملاحظات
- لا أعتبر APK جاهزاً قبل نجاح تشغيل البناء وظهور ملف artifact فعلي.
- الأيقونة `icon.svg` تستخدم الصورة المضمنة في الملف، بينما رسم واجهة الترحيب ما زال تعبيرياً.
- المحتوى مناسب كبداية لـ KG1 ويُفضّل متابعة الطفل أثناء التعلم ومراجعة تقدمه.
