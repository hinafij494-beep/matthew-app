# الملك ماثيو 👑

تطبيق تعليمي تفاعلي للأطفال في مرحلة KG1، يعمل بأسلوب Offline-First ومهيأ للبناء كتطبيق Android باستخدام Capacitor.

## أقسام التطبيق

### أكاديمية التعلم
- مدرسة الحروف العربية: الحروف الـ٢٨، أشكال الحرف، الفتحة والضمة والكسرة والسكون، ثم اختبار.
- English Alphabet: الحروف A–Z مع كلمة ومثال صوتي لكل حرف.
- الأرقام العربية ١–٢٠ والأرقام الإنجليزية 1–20.
- رحلة الحساب بالعربي وMath in English: العدّ والجمع والطرح والمقارنة حتى ٢٠.
- أكاديمية العلوم: الحيوانات والنباتات وجسم الإنسان والفيزياء المبسطة والكيمياء والألوان والطبيعة والكون.
- أساسيات البرمجة والمنطق: الاتجاهات والأنماط وترتيب الخطوات وحل المشكلات.

### نظام الإتقان والمراجعة (جديد)
- كل إجابة في الاختبارات والدروس والحساب والقراءة والتتبّع تُسجَّل لمهارة محددة في `mastery.js`.
- التكرار المتباعد: الإجابة الصحيحة مرتين متتاليتين ترفع المهارة درجة في سلم مراجعة (اليوم، بكرة، ٣ أيام، أسبوع، أسبوعين)، والغلطة تنزّل درجة واحدة فقط وترجّع المهارة للمراجعة القريبة.
- أسئلة الاختبار تُختار بترجيح ذكي: المهارات المستحقة للمراجعة أو الضعيفة تظهر أكثر، والمهارات المتقنة تستريح.

### لوحة ولي الأمر (جديد)
- بطاقة «لوحة ولي الأمر» في أكاديمية التعلم، محمية بسؤال جمع بسيط للكبار.
- تعرض الدقة العامة، والمهارات المتقنة، والتقدم حسب القسم، والمهارات المستحقة للمراجعة اليوم، وتوصية عملية للجلسة التالية، وآخر جلسات الاختبار.

### اكتب بإصبعك (جديد)
- تتبّع باللمس للحروف العربية والإنجليزية والأرقام العربية والإنجليزية على Canvas، بقياس تغطية فعلي لشكل الحرف، ومكافأة عند إكمال التتبّع.

### يلا نقرأ (جديد)
- مقاطع عربية بالفتحة والكسرة والضمة والمد، ثم دمج المقاطع لبناء كلمات حقيقية، وكلمات إنجليزية قصيرة CVC مقسمة لأصواتها، مع تحدي استماع واختيار.

### تحديات الملك ماثيو
- بنك أسئلة عشوائي ومتجدد للحروف والأرقام والألوان والأشكال والعلوم والحيوانات والنباتات والفيزياء والكيمياء والفضاء والبرمجة والمعلومات العامة.
- اختيارات مرئية مع رمز/صورة وكلمة مكتوبة، مع إظهار الإجابة الصحيحة بعد الاختيار.
- ألعاب لمس مستقلة: توصيل الصورة بالكلمة، واسمع واختار الحرف أو الرقم.
- نطق السؤال تلقائياً وزر لإعادة سماعه.
- نجوم ونقاط وكؤوس وسجل آخر ٣٠ نتيجة محفوظة محلياً، مع عرض مستوى رحلة الحساب بالعربية والإنجليزية.

## الصوت

- في APK: يستخدم محرك Android TTS الأصلي عبر `@capacitor-community/text-to-speech` أولاً.
- عند تعذر المحرك الأصلي، يحاول استخدام `window.speechSynthesis` مع انتظار تحميل الأصوات.
- زر **تجربة الصوت** يختبر النطق، ومؤثرات Web Audio تصدر نغمات للأزرار والإجابة الصحيحة والخاطئة.
- اللهجة المصرية `ar-EG` تُطلب من محرك الجهاز؛ جودة اللهجة وتوافرها يعتمدان على الأصوات المثبتة في Android.
- للحصول على نطق دون إنترنت، ثبّت بيانات الصوت العربي والإنجليزي من إعدادات تحويل النص إلى كلام في الهاتف. لا يمكن ضمان العمل دون اتصال إذا كان الهاتف لا يملك صوتاً محلياً للغة.

## العمل دون إنترنت

- جميع الدروس والأسئلة والرسومات الرمزية موجودة محلياً داخل التطبيق.
- APK يضم ملفات الويب داخل التطبيق ولا يحتاج إلى اتصال لفتح المحتوى.
- نسخة PWA تخزن الملفات في Service Worker بعد أول فتح ناجح عبر HTTPS.
- التعرف على كلام الطفل عبر الميكروفون ميزة منفصلة وقد تتطلب اتصالاً بالإنترنت، ولا يعتمد عليها تشغيل الدروس أو نطقها.

## بناء APK

يوجد GitHub Actions workflow باسم **Build Android APK**. يبدأ تلقائياً عند تحديث ملفات التطبيق على فرع `main`، ويمكن تشغيله يدوياً من تبويب Actions. ملف APK الناتج يُحفظ كـ workflow artifact باسم `king-matthew-debug-apk`.

المشروع يستخدم Capacitor 7 مع Android SDK 35 وإضافة TTS المتوافقة معها.
