# الملك ماثيو 👑

تطبيق تعليمي عربي بسيط للأطفال، مصمم ليعمل دون اتصال بعد أول تحميل.

## الموجود حالياً
- خمس مغامرات: الأرقام، الحروف، الألوان والأشكال، معلومات ممتعة، واختبار مفاجآت.
- 8 أسئلة في كل جولة، مع خلط ترتيب الأسئلة والإجابات عشوائياً.
- حفظ النجوم وأفضل نتيجة على نفس الجهاز.
- تصميم متجاوب للموبايل، واتجاه عربي RTL.
- PWA قابلة للتثبيت مع Service Worker للتشغيل دون إنترنت.

## التشغيل
انشر الملفات على GitHub Pages أو أي استضافة HTTPS. افتح رابط الموقع مرة مع الإنترنت حتى يتم تخزين الملفات، وبعدها يمكن فتحه دون اتصال.

## ملاحظات
- زر التثبيت يظهر في المتصفحات الداعمة لتثبيت PWA.
- ملف APK ليس مرفقاً بعد. يمكن تغليف نسخة الويب لاحقاً كتطبيق Android باستخدام Trusted Web Activity أو Capacitor.
- صورة الأيقونة الحالية رسمة رمزية لطفل أمير وليست صورة شخصية لماثيو.
- الأسئلة الحالية نموذج أولي تعليمي، ويجب مراجعتها وتوسيعها قبل الاعتماد المدرسي.
