# الملك ماثيو 👑

تطبيق تعليمي تفاعلي للأطفال في مرحلة KG1، مصمم للموبايل ويدعم التثبيت كـ PWA والعمل دون اتصال بعد أول تحميل ناجح.

## أقسام التطبيق
- مدرسة الحروف العربية: الحروف الـ٢٨، أشكال الحرف، الفتحة والضمة والكسرة والسكون، ثم اختبار.
- English Alphabet: الحروف A–Z مع كلمة ومثال صوتي لكل حرف.
- الأرقام العربية ١–٢٠ والأرقام الإنجليزية 1–20.
- رحلة الحساب بالعربي: شرح وتمارين متدرجة حتى ٢٠.
- Math in English: شرح وتمارين متدرجة باللغة الإنجليزية حتى ٢٠.
- معلومات عامة، ألوان وأشكال، حروف وأرقام، واختبار مفاجآت.
- تحدي النطق بالعربية والإنجليزية (التعرف على الكلام يعتمد على دعم المتصفح وقد يحتاج اتصالاً بالإنترنت).
- حفظ النجوم وأفضل النتائج محلياً على الجهاز.

## التشغيل
انشر المستودع باستخدام GitHub Pages وافتح رابط الموقع عبر HTTPS. افتحه مرة بالإنترنت حتى يكتمل التخزين المؤقت، وبعدها تعمل الدروس والاختبارات الأساسية دون اتصال.

## بناء APK
يوجد GitHub Actions workflow باسم **Build Android APK**. يبدأ تلقائياً عند تحديث ملفات التطبيق على فرع `main`، ويمكن تشغيله يدوياً من تبويب Actions. ملف APK الناتج يُحفظ كـ workflow artifact.

## الصوت والصور
الصوت يستخدم محرك تحويل النص إلى كلام المثبت على الجهاز؛ اختيار اللهجة المصرية يعتمد على الأصوات المتاحة في هاتف Android. لا يمكن ضمان صوت مصري مطابق على كل جهاز. الأيقونة الحالية رسمة رمزية وليست صورة شخصية فوتوغرافية لماثيو.
