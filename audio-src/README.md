# مصادر صوت الميس (Recorded teacher voice)

- `clips.json` — the original 44 fixed lines (round 2).
- `corpus.json` — generated by `../build-corpus.js`: every spoken string in the
  app (quiz questions + answers, science lessons, letter school, reading,
  numbers, story lines). Regenerate with `node build-corpus.js`.
- Audio is synthesized per corpus entry (natural female Egyptian voice),
  encoded as mono Opus, then packed by `../build-voice-clips.py` into
  `voice-clips-pack-*.js` chunks (long clips are split into `key~N` segments
  and rejoined by the runtime) plus `voice-clips-text-1.js` (text -> key map).
- `../build_bundle.py` inlines the chunks into `interactive-games.js` for the
  APK; the Android workflow runs it before copying web assets.

## TTS generation rules (learned 2026-11-11)

- Heavy Arabic diacritics (tashkeel) in the TTS input make the voice drawl:
  the same ~270-char letter lesson rendered at 90-380s instead of ~30s.
  Generate letter/sentence clips from a diacritics-stripped copy of the text
  (the corpus text itself stays vocalized — only the synthesis input is
  cleaned). Repeated letters like "رررر" must be spaced ("ر ر ر ر").
- Reject any clip whose duration is slower than 5 chars/sec; regenerate
  (with the cleaned input) until it lands near the natural ~10 chars/sec.
- Round 3.2: taught letter names/sounds/syllables (`les_namesound_*`,
  `basic_ar_*`, `rd_syl_*`) are recorded in Fusha (`ar_SA`, same Aria
  voice) — the Egyptian dialect renders ج/ق/ث/ذ/ظ non-scholastically.
  `build-corpus.js` forces `ar_SA` for those keys, and `gen6.js` keeps
  diacritics for `ar_SA` (they carry the vowel). A bare single letter
  ("مُ", "آ") can return empty audio: the synthesis input is drilled
  twice ("مُ، مُ") while the corpus text stays one syllable.
- Math operation explanations are recorded with fully spoken text
  ("اتنين زائد اتنين يساوي أربعة") — no `+`/`-`/`=` symbols, and the
  math-journey generators mirror the corpus exactly.
